1 · Implementation summary

A React 19 + TypeScript market dashboard comparing IBM against Microsoft, Oracle, SAP and Salesforce. A small Express proxy using yahoo-finance2 isolates the browser from the third-party API. The UI can also run with sample data and no server (npm run dev:mock).

Three views

ViewWhat it showsComponents
Current DayLatest session, percent change from the open. Shows a "Market closed" notice when data is stale.TodayView, WindowView
Last 7 DaysPercent change from the start of the weekWeekView, WindowView
Last QuarterDaily closes, percent change from the start of the quarterQuarterView, WindowView

All three share WindowView: a Recharts comparison line chart plus a ranking table, with loading, error and retry states.

## Summary
Adds the initial finance dashboard: a React 19 + TypeScript app that compares
IBM against Microsoft, Oracle, SAP and Salesforce across three time windows,
served by an Express proxy that isolates the browser from Yahoo Finance.

## Motivation
Establishes the baseline application for Part 2 of the IBM Bob GitHub SDLC
lab, so later enhancements (e.g. a user-selected company chart) can be
delivered through issues, branches and pull requests.

## What's included
- Dashboards: Current Day, Last 7 Days, Last Quarter. Each has a comparison
  line chart (percent change) and a ranking table. A "Market closed" notice
  appears when the day view holds stale data.
- Data layer: MarketDataService interface with HTTP and mock implementations
  (npm run dev:mock runs with no server).
- Server: /api/health, /api/quotes, /api/history; symbol and window
  validation, in-memory TTL cache (errors are not cached).
- Config: one validated company list in src/config/companies.ts.
- Repo plumbing: CI workflow, PR template, feature-request issue template.
